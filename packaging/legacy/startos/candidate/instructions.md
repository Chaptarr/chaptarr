# BookshelfNG

Open the StartOS **Web UI** interface to configure your library, metadata
provider, indexers, download client, and import settings. The default image is
the standard ChaptarrNG image configured for Hardcover. The existing
BookshelfNG package ID and data volumes remain in place. Use the ChaptarrNG
documentation for configuration, migration, and compatibility details.

See the [ChaptarrNG documentation](https://github.com/snapetech-org/chaptarrng#readme).
