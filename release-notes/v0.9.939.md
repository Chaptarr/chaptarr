This release refreshes ChaptarrNG's NG-branded icons, serves the web UI through cookie-authenticated routes, and handles unusually large Transmission ETA values without breaking queue responses. Downloadable build artifacts now include the frontend. Dependency updates include the FluentValidation, NLog, Swashbuckle, Sentry, and System.IO.Abstractions compatibility work, while the application remains on the supported .NET 10 LTS line.
