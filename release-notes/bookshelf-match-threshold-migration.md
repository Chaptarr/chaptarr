During conversion, ChaptarrNG retains BookshelfNG's numeric import-match setting and maps it to the closest matching mode if none is set: 50–66 Aggressive, 67–82 Balanced, 83–99 Strict. Invalid values stop conversion. This is an approximate policy mapping, not equivalent match behavior.
