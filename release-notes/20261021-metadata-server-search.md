Add New can search the configured metadata server for books and authors. Catalog settings expose Metadata API and Hardcover searches with environment-backed Hardcover credentials, and metadata-server results keep each candidate's author ID when adding a book. Native Hardcover searches now include configured catalogs, while an explicitly selected Goodreads search stays on Goodreads.
