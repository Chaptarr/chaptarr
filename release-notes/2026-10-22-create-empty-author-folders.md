The existing disk-scan setting now creates missing author folders inside the selected root and scan path, and applies the configured folder permissions. The ebook-folder setting also creates the author's configured ebook path. Import matching now strips `_UNPACK_` and `_FAILED_` markers from derived author-folder names, matching the legacy download-folder behavior. Discography releases can be accepted once every included book has been released; incomplete discographies remain filtered.
