Unicode comparison fold data derived from the metadata server generated table
and PostgreSQL lower/unaccent data. PostgreSQL's unaccent generator consumes
UnicodeData.txt and CLDR common/transforms/Latin-ASCII.xml:
https://github.com/postgres/postgres/blob/REL_18_STABLE/contrib/unaccent/Makefile
https://github.com/postgres/postgres/blob/REL_18_STABLE/contrib/unaccent/generate_unaccent_rules.py
The captured table records PostgreSQL 18.6 and source checksums in
UnicodeComparisonFoldData.cs; its exact upstream Unicode/CLDR input versions
are not recorded. Original and applicable upstream notices follow.
