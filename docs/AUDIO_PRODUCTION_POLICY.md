# Recording classification

`AudioProductionConstants.ByLanguage` is the one vocabulary for production markers and collective narrator credits. `AudioProductionDetector` applies it to imports, custom-format scoring, naming, Audible metadata and NFO brand detection. Callers must not add substring checks or their own translated lists.

GraphicAudio and Full Cast Audio are publishers. The generic full-cast production category is not either publisher. The displayed GraphicAudio brand requires explicit GraphicAudio evidence in the publisher, raw file tags, release name or filename (including retained original filenames) only when the file has no nonblank tags. Parent/category folder names and old inferred style fields do not establish it. A legacy `IsGraphicAudio` flag describes detected production style and cannot establish that publisher. Audible's narrator names remain intact; the number of narrators and substrings such as `cast` in a person's name are never brand evidence. Three or more distinct credited narrator names display Full Cast, including anthologies. Automatic detection does not infer production style from narrator count. An explicit edition correction does use the approved count rule and writes an override; naming, custom formats and replacement checks then read that correction.

Brand and production phrases are token-bounded after the existing Unicode normalization. `Graphic Audiobook` and `Undramatized` are not markers. Collective credits can be metadata evidence, but never filename/folder evidence: Chaptarr itself generates Full Cast folder names for recordings with several narrators. Two-credit naming retains the released convention; this classification does not silently shorten those names.

File names, recorded source names and scene/release names may supply style evidence. Folder evidence requires a known import boundary; that boundary and its parent/category are excluded. An old renamed file with no remaining marker cannot be classified from information that was never recorded.

| English collective credits | fullcast; full cast; full cast audio; full cast production; multicast; multi cast; cast performance; ensemble cast; voice cast; cast | Retained metadata vocabulary. | Spanish group-only credits | varios narradores | [Audible narrator listings](https://www.audible.es/search?searchNarrator=narradores), exact-only. |
| Italian group-only credits | narratori vari | [Audible Fontechiara credits](https://www.audible.it/pd/Fontechiara-Audiolibri/886277012X), exact-only. |

Non-English production-style coverage remains incomplete. Unknown text is not guessed or translated. German Hörspiel and Spanish versión dramatizada have provider evidence, but their classification expansion remains pending. Edition-only vocabulary is isolated from the release-title qualifier check. An unrecognised production is not factual proof of standard narration; the current explicit-selection default nevertheless sets Standard when no supported evidence is found. The current guard can detect differences in known evidence, not recover absent or unknown metadata.

`BookFile.AudioProductionOverride` is nullable: omitted on update preserves it; null selects automatic detection; false explicitly selects standard narration; true selects non-standard narration. The file API, successful Manual Import, and explicit Edit Book corrections are three entry points that write it. Observed tags remain unchanged. The Files tab displays classification without an override selector. Pinning or explicitly selecting a native audio edition sets same-row audiobook files' overrides from that stored edition's title/subtitle, publisher, production metadata and cast credits; three or more distinct narrators also count as non-standard for this explicit correction. No recognized evidence means Standard. Choosing print/ebook metadata leaves the recording correction unchanged. Enabling Automatically Switch Edition clears all of this row's audiobook overrides, including Manual Import corrections, to Auto without changing file links. These writes share the book-save transaction and affect only changed rows. Files are not moved, renamed or retagged. Ordinary unchanged saves do not reclassify files. Manual Import retains its correction control. Automatic detection otherwise retains its existing rules.

Automatic same-edition replacement compares effective recording classes. A known class difference waits for Manual Import, including an equal/worse candidate, with the recording difference named first. Otherwise the quality profile decides; equal automatic candidates remain refused, while the authorized equal hand-picked case remains eligible. No null profile grants replacement. Explicit confirmed Manual Replace replaces its listed inventory regardless of class.

The replacement check reuses the shared profile comparer and records elapsed time, file counts and comparison count. Stored custom-format scores are computed once per candidate. This is not a second ranking policy.

Replacement compares file-level recording evidence, excluding shared edition production flags. When both files prove the edition’s complete narrator credits through the existing narrator evidence check, a missing production label does not make them different recordings. Partial credits or the collective label alone do not establish that agreement. Three or more credited narrators display Full Cast only once; legacy combined labels normalize to Dramatized for fewer narrators.
